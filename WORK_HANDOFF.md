# Work handoff — Angel Wars

## Mission
Take the included playable `index.html` prototype to a polished, public browser game under Light & Life Games. The user wants execution and publishing, not repeated planning/approval. User authorizes publishing; verify account access and deployment success before claiming completion.

## Immediate actions
1. Unzip package and run the game in a browser. Fix gameplay bugs, especially victory/restart, touch control and screen resizing.
2. Create a dedicated GitHub repository under the user's established game-development account (confirm correct owner if ambiguous). Commit code, README and license only if approved; do not overwrite unrelated repositories.
3. Enable GitHub Pages from main branch root. Confirm published URL loads on desktop and mobile.
4. Add a Light & Life Games hub card linking to the game. Update game/project tracker if available. Keep other sites untouched.
5. Produce a custom original Angel Wars social share image, favicon, polished OG/Twitter metadata, responsive title screen.
6. Build out to 10 levels, varied enemies and bosses, angel equipment, fortress construction, army formations, class abilities, music/SFX and save data. Maintain a working deployment after every incremental change.
7. Playtest, resolve bugs and provide exact links, commit hashes, tested controls, and remaining issues.

## Constraints
- Keep it free-to-play and browser-first, no downloads, no ads.
- Christian fantasy with respectful framing and no false claim of biblical literalism.
- Mobile-first and playable with mouse/keyboard too.
- Preserve user-owned project files and don't silently rewrite unrelated projects.
- Do not claim live deployment until verified.

## Existing playable prototype
`index.html`: single-file canvas game with 5 waves, angel movement, melee attack, light economy, guardian recruitment, rally/defend, heal, enemies, fortress, boss, victory/defeat and replay.
