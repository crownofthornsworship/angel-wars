# Angel Wars: Heaven's Armies

Free, mobile-first Christian-fantasy action strategy game from Light & Life Games. Open `index.html` in any modern browser.

## Controls
- WASD / arrows: move
- Space or Attack: sword strike
- Q or Recruit: spend 20 Light to summon a guardian
- E or Rally: toggle army follow/defend
- F or Wall: spend 25 Light to build a defense
- R or Skill: use the selected class ability
- On mobile, use the directional and action buttons.

## Current scope
Ten distinct levels, three playable classes, five enemy families, two boss fights, guardian formations, placeable walls, class abilities, sound, responsive controls, and locally saved progress. No external libraries or accounts.

## Biblical framing
Original fantasy inspired by Revelation 12:7; the game does not imply that its fictional elements are directly recorded in Scripture.
